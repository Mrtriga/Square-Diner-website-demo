The Story

An Institution, Not a Trend

Long before Tribeca had a name for itself, there was a diner on this corner. What started as a wooden shack before the Great Depression became a real train-car diner — the kind built to last, not built to impress. Anna and Teddy Karounos run it today the way it's always been run: honest food, fast service, and a room that doesn't pretend to be anything other than what it is.
